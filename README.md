# WISP: Digital Depths

use the skill /skill:scroll-cinematic-sites 

Role & Task: > Act as an elite, award-winning creative front-end developer and 3D web designer (Awwwards / FWA style). Build a high-end, minimalist luxury showcase website for WISP, an agency and creative directory that builds immersive 3D animated websites for premium brands.

Core Concept & Scroll Storytelling: > - Design a continuous, scroll-driven visual journey where each section seamlessly connects into a unified narrative about the evolution of digital space.

As the user scrolls, create a dynamic sense of depth and perspective—as if the visitor is moving through the 3D space rather than just scrolling down a flat page.

Include interactive visual cues: floating minimalist 3D geometric shapes that gently fall or react on scroll, architectural steps with subtle neon purple ambient lighting underneath, and smooth camera parallax transitions.

Color Palette & Visual Aesthetic: > - Dominant: Soft, bold muted white / cream-matte white (matte, editorial luxury finish—avoid harsh 100% pure bright white).

Accent: Vibrant, high-contrast neon purple / electric violet for glows, rim lighting, interactive states, and accent lines.

Tone: Minimalist, futuristic, clean, digital-first luxury with generous open negative space.

Key Sections & Features: > 1. Hero / Introduction: Bold typography for WISP, floating interactive 3D elements, and ambient neon purple underglow. Immediate luxury editorial hook.

2. Interactive 3D Showcase / Directory: A product showcase grid/carousel highlighting interactive 3D web concepts and client builds with fluid hover animations and dynamic lighting.

3. The Narrative / Scroll Mechanism: Smooth section-to-section storytelling with interconnected motion graphics and 3D object movement tied to scroll progress.

4. Agency Capabilities & Philosophy: Crisp micro-copy, refined typography, and sleek digital luxury aesthetic.

5. Footer / Call to Action: Minimalist inquiry section with glowing neon purple interactive elements.
